# Django_PetЕлектронний журнал на Django
Цей проєкт — електронний шкільний журнал, у якому можна керувати інформацією про класи, учнів, вчителів

Що я навчився
Під час створення цього проєкту я:

краще освоїв Django, зокрема class-based views (CBV);

навчився працювати з формами, шаблонами й системою аутентифікації;

реалізував реєстрацію, вхід і вихід користувачів;

використав LoginRequiredMixin для захисту сторінок;

налаштував Bootstrap для базової стилізації;

працював із моделями, пов’язаними між собою через ForeignKey;

зрозумів, як структурувати Django-проєкт для масштабування.

Як запустити проєкт
Клонувати репозиторій:

`git clone https://github.com/vladultimate/Django_Pet`

Встановити Django:
`pip install django`

Застосувати міграції:

`python manage.py migrate`

Запустити локальний сервер:
`python manage.py runserver`

Перейти в браузері за адресою:
`http://127.0.0.1:8000/`
