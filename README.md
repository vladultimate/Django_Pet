# Django_PetЕлектронний журнал на Django
Цей проєкт — електронний шкільний журнал, у якому можна керувати інформацією про класи, учнів, вчителів

## Що я навчився

Під час створення цього проєкту я:

- Почав вчити **Django**;
- навчився працювати з **формами**, **шаблонами** й **системою аутентифікації**;
- реалізував **реєстрацію**, **вхід** і **вихід** користувачів;
- робив застосунки;
- налаштував **Bootstrap** для базової стилізації інтерфейсу;
- працював із **моделями**;
- зрозумів, як структурувати Django-проєкт для подальшого масштабування.

---

Можливості проєкту
 - Перегляд списку всіх класів;
 - Перегляд учнів, прив'язаних до кожного класу;
 - Перегляд списку всіх вчителів;
 - Додавання, редагування та видалення записів про класи, учнів та вчителів;
 - Необхідна аутентифікація для доступу до захищених сторінок.

Опис моделей
 - Class: Представляє клас у школі (наприклад, 5-А).
 - Student: Містить ім’я та прізвище учня, прив'язується до класу за допомогою ForeignKey.
 - Teacher: Містить базову інформацію про кожного вчителя.

## Як запустити проєкт

1. **Клонувати репозиторій:**

    ```bash
    git clone https://github.com/vladultimate/Django_Pet
    cd Django_Pet
    ```

2. **Встановити залежності:**

    ```bash
    pip install django
    ```

3. **Застосувати міграції:**

    ```bash
    python manage.py migrate
    ```

4. **Запустити локальний сервер:**

    ```bash
    python manage.py runserver
    ```

5. **Відкрити в браузері:**

    ```
    http://127.0.0.1:8000/
